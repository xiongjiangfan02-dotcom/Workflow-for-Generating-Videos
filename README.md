# 配音驱动表情短剧工作台

本项目用于将台词拆成分镜，匹配导入的角色表情和场景素材，配合配音生成带字幕的视频。源码位于 `studio/`，功能与使用限制见 `使用说明.md`。

## 运行准备

仓库不包含模型权重、素材、配音、项目数据、本机 Python 环境或构建后的网页。需要自行安装 Python、Node.js、pnpm、FFmpeg 和 `studio/requirements.txt` 中的依赖，在 `studio/` 安装前端依赖并运行 `pnpm build`，然后检查启动脚本和视频工具的路径。

MegaTTS3 需要单独配置模型及独立运行环境，安装记录见 `studio/megatts-install.md`。原使用说明及部分配置包含作者电脑上的绝对路径，其他电脑需要调整；配音、模型及第三方素材的许可需分别核对。

Windows 下完成配置后可运行 `启动工作台.cmd`。工作台默认保存在本机，DeepSeek 分析仅在用户主动选择并提供密钥时使用。
